# QA Portfolio - Automation Exercise Testing

Project automation testing menggunakan **Playwright (JavaScript)** dengan target aplikasi
[Automation Exercise](https://automationexercise.com), diimplementasikan dengan pola
**Page Object Model (POM)**.

## Tech Stack
- Playwright (JavaScript)
- Page Object Model pattern
- GitHub Actions (CI)

## Struktur Project
```
automationexercise-playwright/
├── pages/
├── tests/
├── .github/workflows/
└── playwright.config.js
```

## Cara Menjalankan
```bash
npm install
npx playwright install
npm run test:ui
```
